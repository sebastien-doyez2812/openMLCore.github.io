Loss Functions

Ready-to-use loss function, and the possibility to create custom loss based on classical one. Available in the sub-package openmlcore.loss. Compatible with PyTorch.

DiceLoss

Overlap-based
Stable

Based on the Sørensen–Dice coefficient, it prioritizes the overlap between the ground truth and the prediction. Unlike BCE, Dice Loss operates at the region level. It is very effective for small objects or class imbalance.

Example (weights for multiclass): 
from openmlcore.loss import DiceLoss

weights_for_class = torch.tensor([4.0, 1.0, 4.0, 3.5, 2.0])
myLoss = DiceLoss(weights=weights_for_class)
Key Parameters:
  • weights (Tensor=None): weights for multiclass

BCEWithLogitsLoss

Entropy-based
Stable

BCE is based on a logarithmic difference and works on a pixel-by-pixel basis. It penalizes incorrect predictions more than it rewards correct ones.

Example for multiclass segmentation: : 
from openmlcore.loss import BCEWithLogitsLoss

weights_for_class = torch.tensor([4.0, 1.0, 4.0, 3.5, 2.0])
myLoss = BCEWithLogitsLoss(weights=weights_for_class),
Paramètres clés :
  • Weights (Tensor): Weights for multiclass segmentation

CustomLoss

Composite
Stable

With CustomLoss, you can ponderate classical loss to imporve your finetuning!

Example : Combinaison Dice + BCE (0.7 * Dice + 0.3 * BCE) : 
from openmlcore.loss import CustomLoss, DiceLoss, BCEWithLogitsLoss

weights_for_class = torch.tensor([4.0, 1.0, 4.0, 3.5, 2.0])
weights_type_loss = [0.7, 0.3]

myLoss = CustomLoss(loss_fcns=[ DiceLoss(weights=weights_for_class), BCEWithLogitsLoss(weights=weights_for_class)], name="CustomLoss", coefficients=weights_type_loss)

Performance metrics

Metrics function avilable in openmlcore.metrics to validate the quality of your models.

accuracy

Pixel Accuracy

Return a list of percentage of pixels correctly predicted compared to the ground truth.

Signature : accuracy(y_pred, y_true)
Return : list of float (0.0 to 1.0)
Usage : balanced datasets

iou

IoU / Jacard Index

Intersection over Union (IoU) : Measure of the intersection divided by the union of the prediction and the ground truth.

Signature : iou(y_pred, y_true, smooth=1e-6)
Return : list of float (0.0 to 1.0)
Usage : Standard in segmentation tasks

Precision

Dual Metric

Precision is equal to the real positive (TP) divided by the the predicted positives (TP + FP).

Signature : precision_recall(y_pred, y_true)
Formula : TP / (TP + FP)
Return : List of float(multiclass usage)
Usage : Errors analysis

Recall

Dual Metric

Recall is the division between the true Predicted positivve (TP) and the real positive (TP + FN).

Signature : precision_recall(y_pred, y_true)
Formula : TP / (TP + FN)
Return : List of float(multiclass usage)
Usage : Errors analysis

f1_score

Dice Score

Harmonic mean of precision and recall. Metric equivalent of the Sørensen–Dice coefficient.

Signature : f1_score(y_pred, y_true, eps=1e-7)
Formula : 2 * (P * R) / (P + R)
Return : List of float(multiclass usage)
Usage : imbalanced datasets
